# 初步想法

1. 项目概述与愿景
一句话定位：
在 Injective 区块链上构建全球首个AI驱动的自主电子提单（eBL）与供应链金融智能体，实现从文件流转到自动融资的全流程自动化，并符合 MLETR / eUCP / DCSA 等国际标准。
核心愿景：
把丽讯科技现有的 BL 电子化系统，升级为法律级可转让 + 金融级可融资 + AI自主决策的 eBL 平台，让供应链金融从“人工审核+人工放款”变成“AI判断+链上自动触发”。

2. 市场背景与痛点（为什么现在做有价值）

2026年5月1日中国新《海商法》正式实施，引入 MLETR 原则，eBL 在中国首次获得明确法律地位。
全球供应链仍大量依赖纸质提单，融资周期长、成本高、欺诈风险大。
现有 eBL 平台大多停留在“电子化流程”，缺乏法律级文件控制权 + 金融级自动融资能力。
Injective 在 RWA、Agent 基础设施（iAgent 2.0 + Agent SDK）上有明显优势，适合做“自主金融智能体”。

核心痛点：

文件可信流转难（唯一性、控制权、不可篡改）
融资审核慢、人工成本高
跨境场景合规复杂（MLETR、eUCP、DCSA）
缺乏真正能“自主决策并执行”的 AI Agent

## 合作方案

ENI × 丽讯科技：電子提單（eBL）與供應鏈金融合作提案

一、合作背景

全球供應鏈正加速數字化，電子提單（eBL）已成為物流、跨境貿易與供應鏈金融的核心基礎設施。
麗讯科技在物流數字化、供應鏈管理、全渠道電商中台等領域具備深厚能力；
ENI 則專注於可信文件流轉、不可篡改、唯一性控制、跨企業文件交換等底層技術。

雙方能力高度互補，可共同打造 金融級別的 eBL 解決方案，推動供應鏈金融與跨境貿易的落地。

---

二、合作願景

打造 “物流級別 + 法律級別 + 金融級別” 的電子提單與供應鏈金融平台，
讓麗讯現有的 BL 電子化能力升級為 可轉讓、可驗真、可融資 的 eBL。

最終目標：

• 讓麗讯成為 中國領先的 eBL + 供應鏈金融平台提供商
• 讓 ENI 成為 麗讯 eBL 的底層可信文件引擎


---

三、雙方優勢互補

丽讯科技的優勢

• 深耕物流與供應鏈數字化
• 擁有大量貨代、物流、供應鏈企業客戶
• 具備成熟的業務場景與系統集成能力
• 對 eBL 有需求，但缺乏法律級別與金融級別的能力


ENI 的優勢

• 文件唯一性（Uniqueness）
• 文件不可篡改（Integrity）
• 文件控制權（Control）
• 文件可審計（Auditability）
• 跨企業文件可信流轉
• 能符合 MLETR、eUCP、DCSA 等國際標準的技術架構


→ ENI 的技術正是 eBL 的核心要求。

6.TradeGo已经有了用稳定币结算电子提单银行融资的项目，我导师建议我们保留虚拟货币结算众筹融资的idea，这是我们比Tradego创新的一步
